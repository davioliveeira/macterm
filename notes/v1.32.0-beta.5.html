What's New

  • Custom palettes are now extensions. In Settings → Extensions, you can install the extensions from the Macterm repository with one click: Kubernetes, Git, Docker, SSH and Claude Code. You can search them and filter them by installed. (#527, #531, #541, #550)
  • When the repository changes an installed extension, its card shows an Update button. Turn on Update extensions automatically to apply an update without a click. Macterm never replaces an extension that you changed without asking first. (#556, #563)
  • An extension can bundle its own icon, and each of its palettes shows that icon. The Docker, Kubernetes, Git and Claude Code extensions show the logo of their tool. (#555, #556)
  • A palette or a menu item can say when it cannot be used. For example, the Kubernetes palette mutes its cluster screens while the cluster is down. (#526)
  • Worktrees is now a screen of the Git extension, next to Branches. A palette action can open a shell or run a command in a directory that it names with cwd:. (#564)
  • The SSH extension can add a host as a remote project. (#573)
  • Capture Pane copies the focused pane to the clipboard as an image, with no window blur and nothing from behind the window. (#554)
  • Capture Palette Screenshot makes a screenshot of the command palette at the size that extension screenshots use. (#528, #579)
  • Settings → Updates has one toggle, Update automatically. When a background download is ready, the toolbar shows Restart to Update, and the first launch after an update shows a toast with the new version. (#558, #560, #562)
  • The caption under Update channel describes the channel that you select. (#530)
  • Each row in Settings → Keymaps has one menu for Global and Pass to TUI. To clear a keybind, click it and press Delete. Keymaps also opens faster. (#566, #581)
  • Each window keeps its open project sections in the sidebar across a relaunch. (#559)
  • A toast with a long message stays up longer, so that you can read it. (#580)
  • The text in Settings, alerts, messages and macterm --help is shorter and uses one word for one thing. Settings → General → Text Files is now Opening Text Files. (#537, #538, #565, #575, #584)

Fixes

  • After a quit and a relaunch, a pane's scrollback keeps its width and its last lines. Before, it could come back wrapped at a narrow width, with lines missing. (#578)
  • A launching window shows its text from the first frame, not rows of colored blocks. (#557)
  • Each window keeps its sidebar width across a relaunch. (#553)
  • A project with no tabs stays empty after a relaunch. Selecting it no longer creates a tab. (#548)
  • The command palette opens faster, and the first keystroke into an empty search no longer lags. (#561, #569)
  • When you use the keyboard to move through the palette, the selected row stops clear of the edge again. (#561)
  • Each palette screen and each new search starts at the top of its list. (#543, #546)
  • A palette screen that is not available keeps its icon on its row. (#525)

Notes

  • Macterm reads palettes only from extensions. It no longer reads ~/.config/macterm/palettes/. To keep a palette of your own, put it in an extension: a folder in ~/.config/macterm/extensions/ with an extension.yaml and a palettes/ folder. authors: is optional.
  • The built-in Worktrees screen is gone. Install the Git extension to get it back.
  • Macterm now checks for updates each day for everyone, also if you turned off the old check toggle. The check only reads the update feed.
