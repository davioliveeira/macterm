What's New

  • Macterm adds ~/.config/macterm/config.ghostty to your custom config files. The file lists each default of Macterm as a commented line with a note. A key that you set in it applies only to Macterm, and it wins over your Ghostty config. You can move or remove it in Settings → General → Ghostty Config, as any other config file. Open Macterm Config in the command palette and the View menu opens it. (#588, #590)
  • Update extensions automatically is a checkbox again, and it is on by default. It never replaces an extension that you changed. (#587)

Fixes

  • When Capture Palette Screenshot needs Screen Recording, the toast shows the full step again: if the switch is already on, remove Macterm from the list, then try again. (#589)

Notes

  • If you turned off Update extensions automatically, it stays off.
  • Macterm reads pinned.yaml only from ~/.config/macterm/. It no longer reads the old file in ~/.config/macterm/projects/. Every 1.31 release moved that file up. If you update from 1.30 or earlier, move the file up yourself.

Thanks to @thdxg for this release.
