What's New

  • Extensions: install palettes for Git, SSH, Docker, Kubernetes and Claude Code from Settings → Extensions. Each card shows the screenshots and the icon of its extension. (#527, #528, #531, #541, #547, #550, #555, #594)
  • An installed extension gets an Update button when the repository changes it. Update extensions automatically is on by default, and it never replaces a copy that you changed. (#556, #563, #587)
  • The command palette has screens that nest, and a Files screen that searches the files of the project by name or part of a path. (#511, #512, #519, #520, #525)
  • Extension palettes can show fixed rows above a listing, give a row a ⌥ action, mute a screen that cannot be used, and open a terminal in a directory. Their commands run in the same way in every shell, and a run: action does not go into the history of your shell. (#518, #521, #522, #526, #564)
  • The Git extension lists the worktrees of a project, and the SSH extension can add a host as a remote project. (#505, #564, #573)
  • The Password Manager screen of the command palette types a saved password into the focused pane, also at prompts that Macterm cannot detect. You can bind it to a keybind. (#500, #502)
  • Every search in the app uses one fzf-style ranking, and the palette shows the letters that matched in bold. (#506, #508)
  • Capture Pane copies the focused pane to the clipboard as an image, with no window blur and nothing from behind the window. (#554)
  • Capture Palette saves the open command palette as a screenshot at the size that extensions use. (#528, #592)
  • Macterm can be the default app for text files. It opens them in the editor of $VISUAL or $EDITOR, and ⌘-click on a path:line in a pane opens the file at that line. (#484, #485, #565)
  • Drag a folder onto the sidebar to add it as a project. (#489)
  • Right-click the toolbar to hide it or to move the tab switcher. View → Hide Toolbar does the same. (#482)
  • macterm tab new --no-focus and macterm pane split --no-focus start a terminal in the background and do not move the focus. (#499)
  • Macterm writes ~/.config/macterm/config.ghostty on first launch. It lists the defaults of Macterm as comments, and a key that you set in it applies to Macterm only. (#588, #590)
  • Snap to whole row (Settings → Animations) scrolls a whole row at a time, and each row slides into place, as in less. (#503, #517)
  • The smooth cursor now moves the text under it too, and the cursor trail costs nothing while the cursor does not move. (#490, #493)
  • Splits animate with a shorter tail, and the keyboard Resize Split commands slide the divider. (#494, #495)
  • Panes follow the mouse in the same way as Ghostty.app: hover in a window that is not in front, Look Up with a force click, the ⌃-click menu and focus-follows-mouse. (#491)
  • Each window opens again at its size and position, with its sidebar width and its open project sections. (#498, #553, #559)
  • Settings → Updates has one Update automatically toggle. After a download in the background, the toolbar shows Restart to Update, and the first launch after an update shows the new version. (#530, #558, #560, #562, #575)
  • Settings → Keymaps puts Global and Pass to TUI in one menu on each row. Settings sections link to their docs, and captions are shorter. (#488, #501, #566, #584)

Fixes

  • An OSC 8 link no longer opens a program. A link with a custom scheme asks before it opens. (#483)
  • After a relaunch, the scrollback of a pane keeps its line width, and no lines are missing. (#578)
  • A launching window shows its text at once, not rows of colored blocks. (#557)
  • Right click works in Helix and other crossterm programs after a relaunch. (#492)
  • A new pane no longer shows a session "…" created line. (#487)
  • A project with no tabs stays empty after a relaunch. (#548)
  • A dead remote pane closes on any key, also when the host refuses the connection. (#598)
  • The password bubble comes up about 0.4 s after a prompt, not 1 s or more. (#596)
  • In a second window on the same tab, splits animate and Split Automatically picks the correct direction. (#524)
  • The command palette opens faster. Each screen and each new search starts at the top, and search results are always current. (#543, #546, #561, #569)
  • Capture Palette works when you allow Screen Recording while Macterm runs, and its message shows the full fix. (#579, #589)
  • A toast stays up longer when its text is longer. (#580)

Notes

  • Macterm reads palettes only from extensions. It no longer reads ~/.config/macterm/palettes/. To keep a palette of your own, put it in an extension folder in ~/.config/macterm/extensions/. See the Extensions docs.
  • Macterm no longer reads ~/.config/macterm/projects/pinned.yaml. Every 1.31 release moved this file to ~/.config/macterm/pinned.yaml. If you skip from an older version, move the file yourself.
